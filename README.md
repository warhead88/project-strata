# Project Strata

Глобальная стратегия с детально проработанным миром на нескольких масштабах, от государств и регионов до городских кварталов, отдельных объектов и подземных помещений. Местные условия и свойства объектов имеют последствия для решений игрока. Он сам выбирает место для основания населённого пункта. Заводы и исследовательские центры занимают конкретные места в границах населённого пункта или за его пределами, на поверхности или под землёй.

## Запуск

Из корня Git-репозитория с установленным `rustup` запусти `cargo run --locked`. Сейчас открывается 3D-окно глобуса на Bevy 0.20.1. Версия Rust 1.97.1, Clippy и rustfmt закреплены в `rust-toolchain.toml`.

Пробел приостанавливает и возобновляет игру. Верхняя строка HUD показывает подтверждённое игровое время и состояние часов. Во время паузы камерой можно управлять как обычно.

`cargo verify` проверяет размеры файлов, форматирование и Clippy, затем запускает тесты и сборку всего workspace. `cargo limits` запускает только проверку размеров и охватывает отслеживаемые Git и новые неигнорируемые файлы. Пределы применяются к исходникам, конфигам и текстовому контенту в `content/`. Автоматически создаваемые `Cargo.lock` и `target/` лежат вне этой проверки.

Обычный вывод Cargo приглушён. Для подробного вывода сборки используй `cargo build --verbose`. В запущенном клиенте сообщения зависимостей выводятся с уровня `error`, а сообщения `strata_client` — с уровня `info`. Для диагностики игры фильтр можно переопределить переменной `RUST_LOG`.

## Проектирование игры

Карту, базовые механики, населённые пункты, строительство, экономику и политику прорабатываем в отдельных тредах. Подземное пространство и исследования требуют собственных проектных решений. Для каждой области определяем, какие детали видит игрок, на что он может влиять, как меняется состояние мира и какие данные нужны связанным системам. Принятые решения сохраняем в `docs/`.

Технические прототипы отвечают на конкретные вопросы одной области. Например, прототип карты может проверить, сохраняются ли точные положения и свойства объектов при переходе от обзора мира к отдельному участку на большой карте. Строительство может отдельно проверить, как здание занимает пространство и как разрешаются пересечения на нескольких уровнях. Связи между областями проектируем по мере того, как становятся понятны их правила и необходимые данные.
