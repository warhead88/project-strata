# Project Strata

Глобальная стратегия, в которой политические, экономические и дипломатические решения связаны с тем, что игрок строит на карте. Игрок сам выбирает точку основания каждого города на глобальной карте. Заводы и исследовательские центры занимают конкретные места в городе или за его пределами, на поверхности или под землёй.

## Запуск

Из корня Git-репозитория с установленным `rustup` запусти `cargo run --locked`. Сейчас открывается стартовое окно на Bevy 0.20.1. Версия Rust 1.97.1, Clippy и rustfmt закреплены в `rust-toolchain.toml`.

`cargo verify` проверяет размеры файлов, форматирование и Clippy, затем запускает тесты и сборку всего workspace. `cargo limits` запускает только проверку размеров и охватывает отслеживаемые Git и новые неигнорируемые файлы. Пределы применяются к исходникам, конфигам и текстовому контенту в `content/`. Автоматически создаваемые `Cargo.lock` и `target/` лежат вне этой проверки.

Обычный вывод Cargo приглушён. Для подробного вывода сборки используй `cargo build --verbose`. В запущенном клиенте сообщения зависимостей выводятся с уровня `error`, а сообщения `strata_client` — с уровня `info`. Для диагностики игры фильтр можно переопределить переменной `RUST_LOG`.

## Порядок проектирования

1. **Мир и координаты.** Определить, как одна позиция связывает глобальную карту, участок застройки и уровень под землёй. От этой модели зависят размещение, логистика и сохранения.
2. **Города и объекты.** Определить основание поселения, правила размещения зданий внутри и за городом и связь подземных помещений с поверхностью.
3. **Симуляция.** Описать шаг времени, производство и исследования, затем связь отдельных объектов с экономикой и политикой государства.
4. **Контент.** Определить формат определений зданий и деревьев исследований, идентификаторы, ссылки и их валидацию.

Первый игровой прототип можно проверить на одном регионе. Игрок выбирает точку основания города, строит наземный завод и подземный исследовательский центр, проводит шаг симуляции и видит изменение запасов и прогресса исследования. Этот сценарий связывает карту, строительство и экономику до масштабирования мира.
